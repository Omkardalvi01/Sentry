# Bundled evaluation datasets

These files are included so the documented FUR-API evaluations can run from a fresh clone. The dataset snapshots are copied from their public upstream repositories at the revisions below.

| Dataset | Upstream revision | Included files | Source and terms |
|---|---|---|---|
| FUR-API | `fe63412637b60f7273d71613d9b8d39acd286187` | `FUR-API/dataset/train.csv`, `test.csv`, and the upstream dataset README | [Upstream repository](https://github.com/yijunL/FUR-API). The upstream snapshot has no separate license file; consult the authors for redistribution terms. |
| Vichalana | `5220131969740b5af5f23f14a67cd65c5961a293` | Dataset CSVs, README, and the upstream AGPL-3.0 license | [Upstream repository](https://github.com/Vichalana/vichalana-anomaly-benchmark). Please cite Geethika et al., “Anomaly Detection in High-Performance API Gateways,” HPCS 2019, DOI: [10.1109/HPCS48598.2019.9188100](https://doi.org/10.1109/HPCS48598.2019.9188100). |

The FUR-API repository does not state a data license in this snapshot. The files are provided with attribution for reproducible evaluation; confirm redistribution rights with the authors before reusing them outside this repository.

LO2 is not bundled. Its full dataset is about 450 GB uncompressed, and the locally available sample archive was incomplete.
